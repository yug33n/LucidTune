**LucidTune** — сверхлегковесный настраиваемый музыкальный оверлей и мини-плеер в панели задач для Windows 10 и 11. Выполненный в эстетике тёмного матового стекла в стиле *Apple Dynamic Island*, LucidTune отображает метаданные текущего трека, обложку альбома, прогресс воспроизведения, полосу громкости и удобные элементы управления поверх любых приложений и игр, либо прямо в панели задач Windows.

## ✨ Возможности в версии 2.1.0

### 📌 Мини-плеер в панели задач (Taskbar Dock)
- **Бесшовная интеграция в панель задач Windows:** Перенос управления воспроизведением в панель задач без загромождения рабочего стола.
- **Два режима размещения:**
  - **Справа (у системного трея):** Компактный плеер с динамической адаптивной шириной (от 54px до 150px), автоматически сжимающийся при нехватке места и никогда не перекрывающий значки запущенных программ.
  - **Слева (у меню «Пуск»):** Расширенный вид с крупной обложкой, названием песни, исполнителем, таймлайном и кнопками.
- **Умное смещение от погоды Windows 11:** Автоматически распознает плашку погоды/виджетов Windows 11 слева через UI Automation и системный реестр, аккуратно сдвигаясь правее с комфортным отступом.
- **Регулировка громкости колесом мыши:** Прокрутка колеса мыши над виджетом плавно регулирует системную громкость.

### 📊 Анимированный аудио-спектр (Equalizer Spectrum)
- **Системный WASAPI пик-метр:** Анализ амплитуды звучания в реальном времени через интерфейс `IAudioMeterInformation`.
- **Физическая динамика эквалайзера:** Быстрый отклик (*fast attack*) на биты и бас-бочку, с мягким затуханием (*smooth decay*) на мелодичных фрагментах.
- **Психоакустическая кривая громкости:** Применение логарифмического масштабирования (`Math.Sqrt`), благодаря которому спектр выразительно танцует как на низкой, так и на высокой громкости.
- **Моментальное определение тишины:** Полоски автоматически опускаются в тонкую 2px линию во время пауз, затишья или смены трека. Режим можно включать или выключать в настройках.

### 🌐 Двуязычный интерфейс (Русский и English)
- Мгновенное переключение языка приложения между **Русским (RU)** и **English (EN)** прямо в окне настроек.
- Все элементы интерфейса, подсказки, диалоги, настройки и контекстное меню трея обновляются на лету без перезапуска.

### 🛡️ Discord Rich Presence и фильтрация медиа
- **Живой статус в профиле:** Трансляция трека, автора, обложки альбома и прогресса в реальном времени в профиль Discord.
- **Умный поиск обложек:** Автоматическое разрешение обложек через Яндекс Музыку, Spotify (Deezer), Apple Music и SoundCloud (Genius).
- **Единый фильтр сторонних медиа:** Чекбокс исключает показ видеороликов из браузера (YouTube, Twitch) и голосовых сообщений/видеозаметок Telegram в статусе Discord.

### 🌈 Адаптивная палитра и градиентный перелив обложки
- **Автоматическое извлечение цветов:** Извлекает доминирующие оттенки из текущей обложки и применяет их к акцентам виджета, ползункам и полосе прогресса.
- **Живой перелив фона (Ambient Shimmer):** Мягкий градиентный перелив фона в оттенках обложки текущего альбома.
- **Плавный возврат:** При отсутствии обложки оформление возвращается к выбранной статической теме.

### 🧲 Прилипание к краям экрана и центру (Magnetic Docking)
- Мягкое прилипание виджета к границам монитора и горизонтальному центру при перетаскивании.

### 👻 Режим стримера (Защита от захвата в OBS и Discord)
- Технология Win32 `WDA_EXCLUDEFROMCAPTURE`: оверлей отображается на мониторе, но невидим для OBS Studio, Discord Screen Share и программ скриншотов.

### 🎶 Универсальная интеграция Windows SMTC
- Работает через системный Windows Media Transport Controls: **Spotify, YouTube Music / Chrome, Edge, Firefox, Telegram, VLC, Яндекс Музыка, AIMP, Apple Music**.
- Защита от частых переключений (debounce guard против сбоев).

### ⚙️ Гибкие настройки и глобальные горячие клавиши
- Настраиваемые горячие клавиши для сворачивания/разворачивания (`Alt + M`), паузы, следующего и предыдущего трека.
- Автоматическое скрытие в полноэкранных играх и видео.
- Быстрый сброс положения в центр экрана одной кнопкой.
- Надежный Single-Instance Mutex и логирование ошибок в `%APPDATA%\LucidTune\crash.log`.

## 🖥️ Системные требования

- **ОС**: Windows 10 (Build 19041+) или Windows 11 (x64)
- **Среда выполнения**:
  - **Автономная сборка (Standalone)**: Никаких внешних зависимостей не требуется.
  - **Портативная сборка (Portable)**: Требуется установленный [.NET 9.0 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/9.0)

---

## 🚀 Установка и запуск

### Вариант 1. Автономная сборка (Standalone, рекомендуется)
Работает сразу на любом совместимом ПК без необходимости установки .NET 9:
```powershell
./publish/standalone/LucidTune.exe
```

### Вариант 2. Портативная сборка (Portable)
Компактный файл для систем с уже установленным .NET 9.0 Desktop Runtime:
```powershell
./publish/portable/LucidTune.exe
```

## 🛠️ Сборка из исходников

## ⌨️ Горячие клавиши по умолчанию

| Действие | Сочетание | Описание |
|---|---|---|
| **Скрыть / Показать виджет** | `Alt + M` | Быстрое переключение видимости оверлея |
| **Пауза / Продолжить** | *Настраивается* | Управление воспроизведением |
| **Следующий трек** | *Настраивается* | Переход к следующему треку |
| **Предыдущий трек** | *Настраивается* | Возврат к предыдущему треку |
